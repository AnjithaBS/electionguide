# 🗳️ Election Guide India

An interactive AI-powered assistant designed to simplify the Indian election process and help citizens—especially first-time voters—navigate voting with ease.

## 🚀 Overview
Election Guide India transforms complex election procedures into a simple, step-by-step, and interactive experience. Instead of just providing information, it actively guides users through the entire voting journey.

## 🎯 Features

### ✅ Interactive Voting Checklist
Step-by-step guidance for:
- Voter registration
- Voter list verification
- ID readiness
- Polling booth awareness

**Smart responses:**
- Redirects users based on their answers
- Provides instant help if a step is incomplete

### 🧭 How Elections Work
Simple explanation of:
- Registration
- Campaigning
- Voting using EVM
- Vote counting

**Includes VVPAT explanation for transparency:**
- A paper slip is displayed for 7 seconds to verify your vote.

### 🌐 Real Action Integration
Direct access to official platforms:
- NVSP (National Voters' Service Portal)
- Voter Helpline App
- Voter list checking

### 📊 Check My Readiness (Key Feature)
Displays voting readiness status:
- ✅ Registered
- ✅ ID Ready
- ❌ Booth Not Found

Helps users take final actions before election day

### ♿ Voting Assistance
Support for:
- Persons with Disabilities (PwD)
- Senior citizens

Includes:
- Accessibility info
- Assistance at polling booths
- Home voting (where applicable)

### 📍 Smart Personalization
Detects user state (manual / location-based)
Adapts guidance based on:
- First-time voter status
- Region

### 📅 Election Timeline Awareness
Explains election phases:
- Announcement
- Registration
- Campaign
- Voting (multi-phase)
- Results

## 🛠️ Tech Stack
- AI Prompt Engineering (Google Antigravity)
- Frontend UI (Web-based interface)
- Geolocation API (for state detection)
- External integrations (NVSP, Voter Helpline)
- Python / Django (Backend Engine)

## 🎨 UI/UX Highlights
- Clean card-based layout
- Step-by-step progress indicator (3 stages):
  - 🟧 Setup
  - ⬜ Guidance
  - 🟩 Readiness
- Mobile-friendly design
- Interactive buttons instead of static text

## ⚠️ Disclaimer
This is not an official Election Commission of India (ECI) application. All information is based on publicly available ECI guidelines.
